The whole content as text, decoded as UTF-8 — bytes that are not valid UTF-8 become U+FFFD. For binary data use readBytes. null when the file does not exist or is not readable.

readBytes function

pub fn readBytes(path: string): uint8[]

The raw bytes, undecoded — what readText cannot give: its UTF-8 decoding turns invalid bytes into U+FFFD. An unreadable file reads as empty, the readLines convention; a caller that needs the difference asks exists first. Writing bytes is not here yet: an array has never crossed the native boundary as a PARAMETER, and that machinery is its own change.
