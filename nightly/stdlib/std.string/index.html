StringBuilder class

pub class StringBuilder

Builds a string piece by piece.

s = s + part in a loop is quadratic: every step copies the whole string so far. The builder collects the parts and joins them once.

The backing is a doubling string[], written by hand because this module must not import std.collections.

parts: string[]

The collected pieces; count says how many are filled.

count: int

How many entries of parts are real.

pub static fn new(): StringBuilder

An empty builder.

pub mut fn append(value: string): void

Adds a piece; the backing array doubles when full.

pub mut fn appendLine(value: string): void

Adds the piece and a \n.

pub mut fn appendChar(value: char): void

Adds one character.

pub fn build(): string

The pieces joined once — the point of collecting them. One native call over the filled slice; a left fold would copy the whole result once per piece, the exact cost the builder exists to avoid. Reads and never consumes: building twice yields the same string.
